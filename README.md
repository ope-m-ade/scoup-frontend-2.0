# SCOUP

This is a code bundle for SCOUP. 

## Running the code

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.

## Deployment notes

- CV upload AI extraction requires the backend `OPENAI_API_KEY`. If that key is not configured, the AI extraction feature is unavailable.
- Project collaboration invitations require the latest backend migrations to be applied before deployment.
